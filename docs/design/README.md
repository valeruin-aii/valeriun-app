# Design do Projeto — Valeriun App

Este diretório é dedicado ao **design inicial, especificações visuais, tokens e protótipos** do projeto.

---

## Estrutura Recomendada

```text
docs/design/
├── assets/             # Prints de telas, wireframes, mockups, logos e referências visuais
├── tokens.json         # (Opcional) Tokens de design exportados (cores, espaçamentos, tipografia)
├── design-system.md    # Diretrizes do design system (paleta primária/secundária, fontes, raio de borda)
└── README.md           # Este arquivo
```

---

## Como Adicionar seu Design

1. **Imagens e Mockups**: Salve suas imagens, diagramas ou capturas de tela dentro da pasta [`docs/design/assets/`](file:///c:/Users/luke_/Downloads/valeriun/valeriun-app/docs/design/assets).
2. **Diretrizes e Regras**: Escreva ou cole os padrões visuais e links (ex.: Figma) em [`docs/design/design-system.md`](file:///c:/Users/luke_/Downloads/valeriun/valeriun-app/docs/design/design-system.md) ou diretamente neste diretório.
3. **Lembrete de Regras**:
   - Componentes sempre baseados em **Shadcn UI**.
   - Proibição estrita de emojis na interface e textos.
   - Padrão semântico de cores para modo claro/escuro.
